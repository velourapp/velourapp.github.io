Установка VelourInstall Velour

Velour ставится из Chrome Web Store и дальше обновляется сам. Velour installs from the Chrome Web Store and then updates itself.

Установить из Chrome Web StoreInstall from the Chrome Web Store
Магазин показывает страницу Velour только после входа в аккаунт Google: у расширения отметка 18+. Если страница пустая, войдите и откройте ссылку снова.The store shows the Velour page only after you sign in to your Google account: the extension is rated 18+. If the page is empty, sign in and open the link again.

Уже стоит версия из архива?Already have the archive version?

Новые версии выходят в Chrome Web Store. Версия из архива продолжает работать как есть. New versions come out in the Chrome Web Store. The archive version keeps working as it is.

Для Chrome версия из магазина — отдельное расширение: она откроется пустой, а ваши данные останутся в версии из архива. Две копии сразу не держите: перед установкой из магазина выключите версию из архива переключателем на её карточке в chrome://extensions. Не удаляйте её, если данные вам нужны: удаление их стирает. Если данные вам важны, напишите в поддержку до перехода. To Chrome, the store version is a separate extension: it opens empty, and your data stays in the archive version. Don't keep two copies at once: before installing from the store, turn the archive version off with the switch on its card in chrome://extensions. Don't remove it if you need your data: removing it erases the data. If your data matters to you, write to support before switching.
