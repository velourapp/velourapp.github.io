Рядом с каждой сборкой — её контрольная сумма SHA-256. Сверь её после скачивания: совпала — файл ровно тот, что мы выложили; не совпала — файл повреждён при скачивании или подменён, устанавливать его не надо. Each build is listed with its SHA-256 checksum. Check it after downloading: if it matches, the file is exactly the one we published; if it does not, the file was corrupted in transit or tampered with — do not install it.

Как сверить — WindowsHow to check — Windows

Открой PowerShell в папке со скачанным файлом и выполни (подставь своё имя файла): Open PowerShell in the folder with the downloaded file and run (substitute your file name): 

Get-FileHash .\velour-fansly-1.2.0.zip -Algorithm SHA256 | Format-List

В строке Hash будет 64 символа. Сравни их со строкой из таблицы выше — регистр не важен. Проще всего скопировать оба значения и сравнить поиском, а не глазами. The Hash line contains 64 characters. Compare them with the row in the table above — case does not matter. Easiest is to copy both values and compare them with a search rather than by eye.

Что эта проверка даёт, а что нетWhat this check does and does not prove

Даёт: уверенность, что скачанный архив совпадает с тем, который мы собрали и опубликовали — то есть по дороге его не повредили и не подменили. It does prove: that the archive you downloaded is the same one we built and published — it was not corrupted or swapped along the way.

Не даёт: это не «защита от взлома» и не аудит содержимого. Хэш подтверждает целостность файла, а не безопасность кода внутри него. Что именно расширение может делать с сетью, видно в другом месте — в manifest.json внутри архива: там полный список хостов, куда оно вообще способно обратиться. It does not prove: this is not "hack protection" and not a content audit. A checksum confirms file integrity, not the safety of the code inside. What the extension can do on the network is visible elsewhere — in manifest.json inside the archive, which lists every host it is able to contact at all.
